# 놀이 상자 🦕 ➕ ▦

아이 둘을 위한 놀이 모음. 게임 셋이 하나의 앱에 들어 있고, 앞으로 더 늘어난다.

앱을 열면 **게임 목록**이 나옵니다. 세계관도 이야기도 없습니다 — 카드를 고르거나,
**「아무거나!」** 를 누르면 게임이 번갈아 나오며 판이 쭉 이어집니다.

| | 무엇을 하나 | 무엇이 자라나 |
|---|---|---|
| **공룡 찾기** | 방 안 소파 뒤·탁자 아래에 숨은 공룡을 콕 누릅니다 | 눈으로 찾는 힘 |
| **셈놀이** | 블록으로 왜 그런지 보여 준 뒤 답을 고릅니다 | 수 감각, 사칙연산 |
| **블록 채우기** | 조각을 떨어뜨려 가이드 모양대로 쌓습니다 | 공간 지각, 순서 세우기 |

**셋 다 실패도 점수도 시간 제한도 없습니다.**

## 블록 채우기 — 탭 하나로 되는 테트리스식 Kanoodle

조각은 **떨어져서 쌓입니다.** 빈 칸에 그냥 박아 넣는 게 아니라, 내려가다 걸리는 곳에
섭니다. 그래서 "어디에 놓을까"가 아니라 **"어느 기둥으로 떨어뜨릴까, 무엇을 먼저
떨어뜨릴까"**가 문제가 됩니다.

조작 규칙은 **하나뿐**입니다:

> 손이 **비었을 때** 탭하면 그 조각을 손에 든다. 손에 **들었을 때** 탭하면
> 그 **기둥**으로 조각이 떨어진다.

세로로 어디를 누르든 상관없습니다 — 어차피 중력이 자리를 정합니다.
**취소 버튼도 드래그도 길게 누르기도 없습니다.**
어린 아이 프로필은 손이 비면 조각이 저절로 들려서, 판만 두드려도 놀이가 굴러갑니다.

퍼즐은 **거꾸로 만듭니다** — 먼저 판을 조각으로 빈틈없이 덮은 뒤(그게 해답) 몇 개를
빼서 문제로 줍니다. 다만 중력이 있으니 아무거나 뺄 수 없습니다. 위에 뭔가 얹힌 조각은
떨어뜨려도 제자리까지 못 내려가니까, 빼는 조각은 **위쪽이 뚫린 덩어리**로만 고릅니다.
그래서 **못 푸는 판이 나올 수 없고**, 힌트도 공짜입니다.

순서도 마찬가지로 보장됩니다. 아직 차례가 아닌 조각 — 지금 떨어뜨리면 아래로 내려와야
할 조각을 가둬 버리는 조각 — 은 트레이에서 **옅게 쉬고 있고**, 누르면 "안 돼" 대신
살짝 흔들립니다. 앞으로 뭐가 남았는지는 계속 보입니다. 그래서 아이가 어떤 순서로
골라도 **판이 막다르게 끝나지 않습니다.**

가이드 자리가 아닌 곳에 앉으면 그 칸이 잠깐 흔들리고 조각은 손에 그대로 남습니다 —
판은 건드리지 않습니다. 오래 막혀 있으면 지금 차례인 조각의 자리가 조용히 숨을 쉽니다.

## 아이가 둘이면

첫 화면에서 **공룡 그림**으로 자기를 고릅니다. 글자는 없습니다. 고르면 화면 테두리가
그 색으로 물든 채 유지돼서, 어디서나 “지금 내 차례”가 글 없이 읽힙니다.
마지막 놀이로부터 3시간 안에 다시 켜면 묻지 않고 바로 들어갑니다.

**나눠 갖는 것**: 진도 · 별 · 통계 · 난이도 손잡이 · 세션 길이
**같이 쓰는 것**: **공룡 도감** · 소리 · 잔잔하게

도감이 공용인 이유가 이 앱 설계의 핵심입니다. 형이 41탄에서 처음 만난 공룡이 동생
도감에도 들어오고, 동생이 우연히 찾은 종도 형 도감에 들어옵니다. **형의 실력이
동생에게 선물이 되고, 둘 중 누구도 지지 않는 유일한 진행입니다.**

두 아이의 별·정답률·최고 탄을 나란히 보여 주는 화면은 **아이 화면에 없습니다.**
비교는 부모 화면에만 있습니다.

### 나이대

부모 화면에서 프로필마다 **어린 아이 모드**를 켤 수 있습니다.

| | 어린 아이 (만 4~6세) | 큰 아이 (만 7~8세) |
|---|---|---|
| 셈놀이 — 블록 설명 | **답을 고르기 전에** 먼저 | 답을 고른 뒤 |
| 셈놀이 — 보기 | 2개 | 4개 |
| 한 번에 노는 양 | 10 | 20 |
| 공룡 — 마리 수 | 2 → 3 | 3 → 6 |
| 공룡 — 가림 정도 | 26 → 66% | 30 → 80% |
| 공룡 — 힌트 대기 | 8초 | 13 → 8초 |
| 공룡 — 도감 사냥 | 없음 | 아직 못 만난 종을 우선 배치 |
| 블록 — 격자 | 4×4 → 5×5 | 4×4 → 6×6 |
| 블록 — 조각 자동 들기 | 켬 (판만 두드려도 된다) | 끔 |
| 블록 — 회전 | 없음 | 22번째 판부터 |

## 할수록 도전적이되, 확 어려워지지 않게

두 게임 다 **난이도 축을 여러 개** 씁니다. 하나만 올리면 금방 천장에 닿거나
확 어려워집니다.

**블록 채우기** — 격자 크기(4×4→6×6) · 놓을 조각 수(2→7) · 안내 단계(칸마다 목표색 →
조각 경계만 → 바깥 테두리만) · 회전 필요 여부 · 조각 모양의 복잡도.

**공룡 찾기** — 마리 수 · 가구 수 · 가림 정도 · 작은 종 비율 · 목표 지정 · 닮은 종 미끼 ·
조명 · 힌트 대기. 실제로 가림 정도가 44% → 64% 로 오릅니다(예전에는 어느 탄이든 53~56% 고정).

**셈놀이** — 빈칸 위치 · 보기 근접도 · 항 수 · 연산 혼합 · 복습 간격 ·
시연 길이. 탄의 순서와 규칙은 건드리지 않습니다.

그리고 **조용히 맞춰집니다.** 헤매면 다음 방이 쉬워지고, 잘하면 두 방 뒤에 조금 어려워집니다.
아이 화면에는 아무 표시도 나가지 않고, 어려워질 때는 항상 한 마리/한 문제에만
먼저 적용됩니다. 축하하는 방(10탄 배수)은 언제나 조금 쉽습니다.

**시간을 재지 않습니다.** 신호는 힌트가 몇 번 나왔는지(공룡)와 같은 문제를 몇 번
맞혀 봤는지(개구리)뿐입니다.

## 실행 / 빌드

```bash
./run.sh                                    # 또는 godot --path .
tools/verify.sh                             # 검증 전부
```

안드로이드:

```bash
mkdir -p build/android && godot --headless --path . \
    --export-debug "Android Test APK" "$PWD/build/android/rogame-test.apk"
adb install -r build/android/rogame-test.apk
```

가로 화면(어느 쪽으로 눕혀도 됨), 몰입 모드, 터치로 바로 놀 수 있습니다.

아이폰/아이패드는 맥이 없어도 GitHub Actions 가 IPA 를 만들어 줍니다 —
[`docs/ios-signing.md`](docs/ios-signing.md).
