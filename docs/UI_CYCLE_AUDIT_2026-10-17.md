# 플레이 사이클 UI 일관성 검수 · 별자리 레벨업 팝업 (2026-10-17)

`graphic_design_manager` 담당분의 기록이다. 사용자 요청 두 가지:

1. 「전반적으로 전체 플레잉 사이클 안에서 디자인적으로 일관되지 않은 부분을 전부 잡아줘.」
2. 「골드로는 영웅뽑기만 가능하고, 능력치는 몬스터를 잡은 경험치가 가득차면 노드기반으로 자동으로
   팝업띄워서 능력치 선택하는 방식으로. 노드를 최대한 풍부하게.」

규칙(경험치·레벨·노드 표 `Balance.TALENTS`·`Talents`·`Arena.pick_talent`)과 비행 몬스터의 판정은 메인
소유다. 이 문서는 그 위의 화면이다 — 사이클 전체를 실제 렌더로 돌며 찾은 어긋남과 고친 것, 레벨업
팝업·별자리 열람의 설계, 상단 띠의 성장 칸, 대공·비행 표식, 검수 자료.

구현 파일: `core/look.gd`(토큰·공용 조각), `game/constellation.gd`(별자리 지도), `game/arena_screen.gd`
(그리기 전부), `game/summon_art.gd`(특성 칩), `game/hero_view.gd`(공격 설명의 대공/지상), `game/menu_overlay.gd`,
`game/collection_view.gd`, `game/store_view.gd`, `game/title_screen.gd`, `core/locales/ui.json`(문구).
`_action` 의 id·뜻, `_process`·`_input`·`_pointer`, `Arena.*` 호출은 바꾸지 않았다.

검수 자료: `build/ui-cycle-2026-10-17/before/`(손대기 전 트리)와 `after/`(지금), 각각 `1280x800/`·`1000x625/`
에 `<ko|en>_<상태>.png` + 같은 이름의 `.json`(그린 글·터치 영역), `sheets/<크기>_<언어>_contact.jpg`(한눈에),
`sheets/<크기>_<언어>_motion.jpg`(팝업 등장 연속 프레임). 재현: `python3 tests/ui_cycle_review.py
--out-root build/ui-cycle-2026-10-17/after` (`--only title,card,rite,hud,talent,bench,shop,menu,result,motion`,
`--sizes`, `--locales`). 장면은 `tests/ui_cycle_preview.gd` 가 실제 판·시뮬·대역 상점으로 만든다.

## 1. 하나의 시각 언어 — 토큰과 규칙

사이클을 돌며 같은 뜻을 다른 모양으로 그리던 곳을 아래 규칙 하나로 모았다. 값은 `core/look.gd` 에 있다.

| 역할 | 규칙 |
|---|---|
| **판(frame)** | 게임 위에 뜨는 판은 전부 **유리**(`Look.glass_panel`, 5px 모따기, `STEEL` 테). 모달 한 장은 `Look.sheet`(그림자 + 유리). 상태가 테 색을 바꾼다: 승리 `GOLD`, 보스 `BOSS`, 별자리 카드는 그 별자리 색. `material_panel`(둥근 9px)은 영웅 카드처럼 **손에 쥐는 물건**에만 남는다 |
| **버튼** | 동작 버튼은 어디서나 `Ui.button`(둥근 베벨 7): 주요 `GOLD` 25px · 보조 `PANEL_EDGE` 23px. HUD 의 레일·칩·메뉴·KOR/ENG 는 `Ui.glass_button` — 타이틀도 전장과 같은 유리다 |
| **칩** | 상태 칩은 `Look.chip`: 단색 면에 어두운 글자(탄 번호 `GOLD`, 레벨 `STARLIGHT`, 마지막 탄 `WARN`, 「전투 정지」는 `STEEL` 22% 면에 `INK_DIM`) |
| **글자 크기** | 모달 제목 34 `GOLD`(`TYPE_TITLE`) · 소제목/카드 이름 23~28 · 본문 19~20 · 캡션 15~16 · 레일 값 13~14 · 표시용 숫자 104. 사이 값은 쓰지 않는다 |
| **색** | 경고 `WARN #ff9a8c`(마지막 탄·보스 초읽기·패배·다 쓴 가호) · 가장 밝은 금 `IVORY #fff0c7` · 경험치와 별자리의 별 `STARLIGHT #fff0b8`(의식판의 `LIGHT`, 5성 색) · 테 `STEEL #84a8b5` · 빈 핍 `STEEL_DIM #6f8794` · 못 누르는 글 `INK_MUTE #8b9aa5` · 수정 판 위의 글 `CRYSTAL_INK` · 보스 테 `BOSS #be797e` · 비행/대공 `AIR`(= `CRYSTAL #5fe6ff`, 병기 별자리의 대공 노드 색) · 유리 면 `GLASS_FACE`/`GLASS_DEEP` · 모달 그늘 `SHADE`(0.84; 패배 위의 구매창만 0.87). 화면 고유의 물건 색(동전·수정 면·조이스틱·세 기술·길 도식·파편)은 그 화면의 이름 붙은 상수다 |
| **숫자** | 골드 `480 G`, 받은 골드 `+140 G`, 배수 `x1.20`/`x2`, 진행은 줄에서 `8 / 14`(띄움), 60px 아래의 칩에서만 `2/6`(붙임). 반복 노드는 카드에서 별 핍 + `1 / 3 번 이음`, 목록에서는 이름 뒤 `x2` |
| **문양** | 공격 속성 = 원 · 몬스터 몸 = 사각 · 등급 = 별 · 구분/핍 = 마름모 · 입구 = 산호 다트 · **비행 = 날개**(`Look.draw_wing`, 원도 사각도 아닌 특성 표식) · **대공 = 원 안의 오르는 화살**(`Look.draw_anti_air`, 속성 원과 같은 상감) |
| **문구** | 화면 글은 전부 사전을 거친다. 전장 화면의 글은 `arena.*` 열쇠(이번에 `empty_slot`·`stars_in_gate`·`free_n`·`best_tier`·`respin`·`stars_joined`·`talent_joined`·`talent_instant`·`talent_depth` 를 더함). 다시 돌리기는 **조작명 + 따로 난 칸**(2026-10-07 기준), 소환 버튼은 별이 다 서면 「2성 소환」 |

## 3. 별자리 레벨업 팝업 (`Arena.modal == "talent"`, 제안이 있을 때)

이 게임의 정체성은 별이다 — 의식은 별을 문에 세우고, 레벨업은 **별을 이어 별자리를 만든다.** 팝업은
전투를 멈춘 밤하늘 위의 한 순간이다(`_draw_talent`, `game/constellation.gd`).

- **그늘과 밤하늘**: `SHADE` 위에 흐린 별 56개(씨앗 고정, 점 하나씩 — 매 프레임 그리는 2D 라 가볍다).
- **머리**: 떠오르는 별 + 「별이 떠오릅니다」 34 금색 + 레벨 칩(`STARLIGHT`) 한 줄, 아래 안내 20, 그 아래
  **경험치 줄**(`경험치 0 / 24` + 200px 별빛 막대, 둘을 한 덩이로 가운데) — 상단 띠의 성장 칸과 같은 읽기.
- **카드 셋**(318×452, 사이 22, y 196): 위에서 아래로
  1. 별자리 띠 — 그 별자리의 색 그라데이션, 별 + 이름(18, 그 색) 왼쪽, 설명(14, 「공격력」 등) 오른쪽.
  2. **별자리 지도**(286×104) — 이 별자리의 노드 전부. 뿌리가 아래, 깊이 3이 위(`Constellation.map`:
     깊이별 줄, 자식은 부모의 평균 x 쪽으로, 겹치면 벌림). 선행 조건이 선이다(「그중 하나」는 점선).
     이은 별 = 찬 별(그 색) · 지금 고를 수 있는 별 = 빈 별 · 아직 먼 별 = 점 · **제안된 별 = 별빛 큰 별 +
     숨 쉬는 고리**. 「이 별이 어디에 서는가」가 한눈에 보인다.
  3. 문양 메달(`Look.draw_passive_icon`, 노드 tint) · **깊이는 별 셋 중 켜진 수**(★☆☆ / ★★☆ / ★★★, 숫자 없음).
  4. 이름 26 · 효과 19(두 줄, 세 줄이면 글만 줄어든다) · 되풀이 노드는 별 핍 + 「1 / 3 번 이음」, 한 번
     걸리는 노드는 「고르는 순간 한 번 걸립니다」.
  5. 주요 버튼 「이 별을 잇는다」(금색 22, 274×50).
- **남은 레벨**: `pending_levels > 1` 이면 「고를 레벨이 2개 더 남았습니다」 + 남은 수만큼 별 핍(수정색, 재촉하는
  것 없음 — 타이머·강조·깜빡임을 두지 않는다).
- **별자리 띠**(y 698, 셀 여덟): 별자리 이름(그 색)·`이은 / 전체`·노드마다 점 하나(이으면 별). 제안된 별자리의
  셀은 그 색으로 옅게 켠다.
- **등장**(`t` 로 돌고, 멈춘 화면은 자리 잡은 모습): 그늘 0.18초 → 별이 26px 떠오르며 머리 0.04~0.34초 →
  카드가 0.14초부터 0.07초 간격으로 22px 떠오르며 0.26초에 자리(`TALENT_*`). 같은 팝업에서 다음 제안이
  나오면 카드만 다시 뜬다. **버튼은 처음부터 듣는다** — 결과 화면과 달리 막는 층을 두지 않았다(팝업은 처치에
  열리지 손가락 아래에서 열리지 않고, `tests/arena_play_check` 가 0.05초에 누른다).
  → **2026-10-19 폐기**(사용자 F1 「버튼이 먼저 빠르게 떠서 관성으로 누른다」): 위→아래 등장, 버튼은 맨 마지막에 나오고
  무장(첫 제안 0.90초) 뒤에만 들으며 뗄 때 확정. 기준은 `docs/DESIGN_SYSTEM.md` 「2026-10-19 별자리」 절.
- **고른 뒤**: 전장으로 돌아온 배너 줄에 1.8초 동안 「별을 이었습니다 · 분노 / 날선 손끝」 유리 판(그 별자리
  색 테, 별 하나가 돋음, 끝에 흐려짐 — `_draw_pick_banner`, 돌파·가호 배너보다 뒤 순위). 화면은 `Arena.talents`
  의 수가 오른 것을 보고 알아챈다(`_watch_picks`) — `_action` 은 건드리지 않았다.
- 1000×625 에서 효과 글 19 → 14.8px, 이름 26 → 20px, 띠 글 13~14 → 10~11px(띠는 보조 정보). 영문 최장 효과
  「Hits on flying monsters slow them to x0.70 for 1.5 s」·「Each kill stacks attack speed x1.05 (up to x1.45, 3 s)」
  두 줄에 든다(`after/1000x625/en_talent_offer_long.png`).

## 4. 별자리 열람 (제안이 없을 때, 레일의 「별자리 · 레벨 N」)

- 머리: 「별자리」 34 + 레벨 칩, 「이은 별 21개」(없으면 「아직 이은 별이 없습니다 …」).
- **첫 페이지**: 여덟 별자리 판(262×236, 4×2). 판마다 띠(이름·설명·`이은 / 전체`), 지도(238×118, 이은 별 켜짐·
  열린 별 빈 별·먼 별 점), 아래에 이은 별의 이름(「빠른 손 x2 · …」 14px, 두 줄). 하나도 안 이은 별자리는
  테와 띠가 흐리다.
- **둘째 페이지**(`talent:next`, 이은 별이 있을 때만): 이은 별 목록 — 문양·이름 `x2`·별자리·효과 한 줄, 두 열
  열두 줄, 넘치면 「+N」. 「<」「>」는 그때만 그린다.
- 「전투로 돌아가기」(금색 23) 는 늘 같은 자리.

## 5. HUD

- **성장 칸**(`_draw_growth_cell`, x 650~768): 1줄 동전 + `480 G`(20, 금색) · 2줄 「레벨 4」(14, `INK_DIM`) 와
  `8 / 14`(12, 오른쪽) · 3줄 별빛 막대(5px, 차면 흰빛으로 숨 쉼). 골드는 의식의 돈, 레벨은 별자리의 돈 —
  둘이 한 칸이다. 1000×625 에서 숫자 높이 약 9~11px(보조).
- **레일** 「별자리 / 레벨 N」(기존 명령 버튼).
- **영웅 카드**: 총·활(`Balance.anti_air`)은 등급 줄 끝에 대공 표식(r 7). 다른 카드에는 아무것도 없다(지상
  공격이 기본이다 — 카드를 깨끗하게).
- **전장 카드**: 날아다니는 몬스터(`Balance.flies`)의 썸네일 오른쪽 위에 날개, 「등장 몬스터」 머리 오른쪽에
  날개 + 「비행」, 보스가 날면 몸 줄 옆에 같은 것(지금 나는 보스는 없다).
- **체력 바**: `_monster_top` 이 비행 몬스터는 노드 메타 `_stellar_fly_height`(몬스터 담당이 매 프레임 발행)를
  더한다 — 보스처럼 몸을 따라간다. 노드가 아직 없으면 1.2u 로 친다.

## 8. 남은 것

- Android/iOS 실기기에서 보지 못했다. 팝업의 별자리 지도는 1000×625 에서 노드 점이 2~4px 다 — 폰에서는
  이은 별·제안된 별만 읽히면 된다(이름·효과는 글이 말한다).
- 레거시 편성·상점 화면(`draw_screen`·`shop_screen`·`battle_screen`)은 사이클 밖이라 손대지 않았다. 거기 남은
  금속 판·베벨 버튼은 그 화면들을 지울 때 함께 간다.
- 레벨업 소리는 기존 `theme`(팝업 열림)·`summon_burst`(고름)뿐이다. 귀로 듣는 검수는 하지 않았다.
