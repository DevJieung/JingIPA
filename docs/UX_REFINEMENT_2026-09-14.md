# 전투 효과와 화면 가독성 보완

## 밀어내기

- `game/battle_sim.gd`: 맞는 순간 경로 좌표를 34px 변경하던 동작을 남은 거리와 시간으로 예약한다.
- 단발은 0.28초 동안 감속하며 밀린다. 실제 경로 좌표를 갱신하므로 표시, 사거리, 피격 좌표가 일치한다.
- 전진 이동을 함께 계산해 기존 34px 밀림이 추가 마비 시간으로 변하지 않게 했다.
- 동시·연속 명중은 남은 거리를 보존하되 시간을 늘려 단발보다 빨라지지 않는다. 몬스터당 총 170px 제한은 유지한다.
- 입구에서는 경로 바깥으로 밀 거리를 쌓지 않는다. 마비 중에도 외력으로 밀리지만 보행 애니메이션은 정지 상태를 유지한다.
- `tests/push_check.tscn`: 30/60/120fps, 양쪽 경로, 실제 물 특효 명중, 연속 명중, 감속, 총량 제한, 입구, 마비, 긴 프레임을 확인한다.

## 블랭크 범위 조사

- 블랭크도 다른 장판 영웅과 동일한 기본 반경 128px에 범위 패시브 배수를 사용한다.
- `tests/element_aoe_check.tscn`에서 중심과 반경 경계의 적만 피해를 받고 경계보다 1px 바깥의 적은 피해를 받지 않는 것을 확인했다.
- 실제 피해 반경·피해량·시전 지연·피해 틱은 변경하지 않는다. 범위가 과장돼 보이는 부분은 `AreaFx`의 시각 표현에서 조정한다.

## 기존 검사와 현재 규칙의 차이

- 현재 규칙은 `docs/REWARDS_AND_FUSION.md`의 12인 출전·중복 카드 별도 보관·공격 중첩 없음이다.
- 구형 `formation_check`는 6인 출전을 기대해 6건 실패하고, `dmg_check --selftest`는 공격 중첩을 기대하고 사거리 도입 전 배치를 사용해 207건 실패한다.
- 밀림 변경만 되돌린 격리 프로젝트에서도 같은 실패 수를 확인했다. 이번 변경으로 생긴 회귀로 취급하지 않았으며, 테스트 통과를 위해 현재 게임 규칙을 되돌리지 않았다.
- 비교 로그: `build/ux-refinement/formation_check-before-push.log`, `dmg_check-before-push.log`.
- 최신 `rules_check`, `range_check`, `flow_check`, `presentation_check`, `element_aoe_check`, `monster_check`, `all_hero_sprites_check` 및 새 밀림 검사를 사용한다.

## 시각 구현과 검수

전담 `graphic_design_manager`가 구현과 실제 화면 검수를 수행했다.

- 전기 아이콘의 원형 받침을 제거하고 감전은 몬스터 윤곽을 따라 가는 금색·백색 방전으로 표현한다. 검은 바닥 원과 불투명 상태 소재를 사용하지 않는다.
- 공통 희귀도 배지는 주어진 폭 안에 배치하고, 선택 표시와 자리를 분리한다. 좁은 카드의 공격 역할과 사거리도 줄을 나눠 표시한다.
- 배치 지도 영웅은 전투 실루엣과 대비판으로 식별력을 높이고 이름·별을 분리했다. 선택한 영웅은 우측에 100px 확대 원화와 이동 안내를 표시한다.
- 다섯 지형 모두 노면 명암과 연석 대비를 높여 몬스터 길을 배경과 구분한다.
- 블랭크를 포함한 광역 중심 폭발과 파편을 실제 피해 원 안에 수용하고 예고 단계와 구분한다.
- 실제 Godot 1280×800 / 1000×625에서 타이틀·뽑기·최고 희귀도 확정·테마·배치·전당·영웅 상세·전투·상점·도움말·합성·카드 선택·게임 종료 화면을 검수했다. 감전 8프레임, 밀림 19프레임과 광역 연속 장면도 두 해상도에서 확인했다.
- 대표 자료: [작은 화면 전체 검수](../build/visual-refinement/1000x625/review_contact.png), [영웅 배치](../build/visual-refinement/1000x625/newfield.png), [몬스터 길](../build/visual-refinement/1000x625/map.png), [블랭크 폭발](../build/visual-refinement/1000x625/area_03.png), [감전](../build/visual-refinement/1000x625/stun_03.png), [밀림 연속 화면](../build/visual-refinement/1000x625/push_sequence.png).
