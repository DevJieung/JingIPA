공통 `Look.text_box`는 번역 후 글꼴 폭·높이를 측정한다. `text_center_fit`,
`HeroCard._text_left_fit`, `wrap_text`는 글자를 …로 버리지 않고 전체 내용이 들어가도록
크기를 조정한다. 실제 최종 호출은 `draw_string(..., width=-1)`이므로 폭으로 글자를
잘라 숨기지 않는다. 카드10처럼 원래 최소 글꼴보다 작은 칸은 글자 영역도 같이 넓혔다.

전체 실측은 각 해상도24,200건 실패0이며 최소10px은52장 선택창의 미니카드 숫자다.
영어Deactivate는 최초9px에서14px 이상으로 개선했다. 상단19자리 골드는 한국어21px,
영어19px에서 네 항목이 모두 같은 크기다. 일반6자리 골드와50테마 상단은 최대24px
기준에서 실제 긴 테마에만 동일하게 축소한다.

raw 문자열 겹침 후보에는 타이틀카드의 draw_set_transform 이전 로컬좌표와 모달에
가려진 배경 글자가 포함된다. 이864건은 실제 화면으로 분류했고,실제 위험3건은
포커 족보 리본과 우하단10의 겹침이었다. 리본의 왼쪽 여백과 폭을 바꿔 숫자를 보존하고
두 해상도 각1,700건의 후속 검사와 실제 촬영에서 포커화면 글자 겹침0건을 확인했다. 따라서 단순폭검사 통과만으로 가림이 없다고 판정하지 않았다.
