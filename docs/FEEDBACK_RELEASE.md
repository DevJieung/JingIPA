# 2026-09-14 사용자 피드백 반영

## 기능과 표현

- 전기 → 나무 상성을 0배에서 0.5배로 수정했다. 바위의 전기 면역과 전기 기본 화력은 유지한다.
- 카드 선택 화면에 마녀 딜러와 말풍선을 배치했다. 제출한 카드를 모으고 주술을 충전한 뒤 영웅으로 터지는 소환 연출을 적용했다.
- 소환 결과를 세로 중앙 쪽으로 올리고, 영웅은 왼쪽·직관적 설명과 스탯은 오른쪽에 배치했다. 중복 족보·공격 유형 나열 대신 5개 별 척도를 사용한다.
- 트럼프 숫자·무늬·외곽의 그리기를 정리하고 J/Q/K 중앙 일러스트를 교체했다.
- 영웅 합성 팝업을 닫을 때 원래 야영지/배치 탭을 유지한다. 모달과 합성 결과가 열려 있으면 메뉴·도움말과 Android 뒤로 가기를 통한 메뉴 열기도 차단한다.
- 합성 카드 수렴·충전·폭발 연출을 추가하고 숫자 등급·강화 실패 문구 대신 별·속성·영웅 특징을 표시한다. 기존 광고 재료 복구 기능은 유지한다.
- 테마 소개는 테마명·등장 속성·꿀팁·터치 시작 안내로 정리했다.
- 카드 교체 광고 버튼·선택창·보상 지급 경로를 제거했다. 무료 횟수와 골드가 부족하면 교체만 비활성화되고 현재 패로 족보를 확정할 수 있다.
- 몬스터 처치 시 골드 획득 숫자를 제거했다. 전투 결과는 평이한 제목과 영웅별 피해량, 잃어버린 크리스탈·최종 획득 Gold 박스로 구성한다.
- 우측 전투 패널의 남은 몬스터·초당 피해·성역 인원·전당 인원 표기를 제거하고 피해량 목록의 세로 공간을 늘렸다.
- 전장 선택 영웅의 강조를 보강했다. 야영지 탭 상태를 통일하고 Next Stage와 몬스터 목록을 탭 위로 옮겼다.
- 광역 연출의 약점·희귀도에 따른 반경 확대를 없앴다. 광역 10명, 범위 강화, 일반 폭발, 분열, 들불의 실제 피해 범위와 시각 범위를 검사했다.
- ElevenLabs BGM 4곡을 추가하고 기존 효과음 42개를 모두 교체했다. 소환·합성 효과음 5개를 추가했다. 상세 내용은 [오디오 기록](AUDIO_REFRESH.md).

## 검증

재현 명령: `python3 tools/verify_feedback.py`

`build/feedback-verification/`에 현재 실행 로그를 저장한다. import, 규칙 1,529건, 사거리 569건, 저장/진행 109건, 화면 동작 328건, 기존 광역 118건, 광역 전수 1,051건, 전체 영웅 2,084건, strict 종합 검사, 오디오 77건, 두 해상도의 실제 팝업 입력 각 43건을 통과했다.

종합 검사의 옛 6인 편성·중첩·고정 카드 더미·즉시 패배 정산 기대값을 현재 12인 편성·복사본 전당·무작위 교체·패배 확정 시 정산 규칙에 맞췄다. 한 틱의 발사 뒤 다음 조준을 지난 발사의 모션으로 잘못 비교하던 검사도 이벤트 순서대로 관측하도록 수정했다. 이를 위해 실제 공격 판정이나 발사 타이밍을 바꾸지는 않았다.

시각 검수 자료는 `build/dealer-refresh/1280x800/`, `build/dealer-refresh/1000x625/`에 있다. 마녀·트럼프·소환·합성·전당·테마·전투·결과·메뉴 화면과 연속 프레임을 기록한다. 시각 구현과 최종 검수는 전담 Graphic Design Manager가 담당했다.

APK 빌드는 `tools/build_apk.sh`로 수행한다. 서명·광고 플러그인·출고 음원/마녀/카드 리소스를 확인한 성공 파일만 `/home/dgxmaruta/pokerdefense-test.apk`에 원자적으로 교체한다. API 키와 생성 원본 음원은 APK에서 제외한다.

연결된 Android 실기기의 터치·광고 재생·스피커 청취 검사는 수행하지 않았다.
