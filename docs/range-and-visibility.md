# 캐릭터 가림 수정·사거리·난이도 조정

2026-09-11 추가 요청을 반영했습니다. 앞선 화면 개선과 생성 이미지는 그대로 사용합니다.

## 캐릭터 표시 순서

- 지형 → 광역·상태이상·투사체·날씨·섬광 → 몬스터 몸체 → 영웅 몸체 → 정보 UI 순서로 그립니다.
- 그림자와 상태이상 그림을 몸체와 분리해 다른 캐릭터의 효과에도 가려지지 않게 했습니다.
- 뽑기 화면에서도 입자·전체 섬광 뒤에 획득 영웅과 글자를 그립니다.
- 재현 화면: `python3 tools/screenshot.py layers --out build/range-shots`. 영웅 12명 발밑에 광역 공격·희귀 착탄·약점 효과와 전체 섬광을 겹칩니다.

## 사거리

모든 50개 캐릭터에 유한한 사거리를 적용합니다. 영웅 발판에서 몬스터 중심까지 측정하며 배치 이동 즉시 새 위치를 사용합니다.

| 무기 | 기본 사거리 |
| --- | ---: |
| 검 | 170 |
| 채찍 | 205 |
| 카드 | 235 |
| 총 | 285 |
| 활 | 320 |

`round((무기 기본값 + 족보 등급 × 6) × 공격 성향 보정)`을 160~400 범위로 제한합니다. 등급은 0~9이며 성향 보정은 연사 0.93, 균형 1.00, 일격 0.97, 정밀 1.10입니다. 공격력 강화로 사거리가 늘어나지 않습니다.

- 겨눌 때와 실제 발사·시전할 때 모두 범위 안의 가까운 적을 고릅니다. 준비 중 이동하거나 적이 벗어나 대상이 없어지면 발사를 취소하고 쿨다운을 풉니다.
- 광선의 추가 대상과 장판의 최초 시전 위치도 영웅 사거리 안으로 제한합니다.
- 이미 발사한 투사체, 연쇄의 도약 거리, 광역 반경과 생성된 장판의 수명은 각 공격의 기존 규칙을 따릅니다.
- 영웅 카드·상세 정보에 수치를 표시하고, 성역 배치·전투 중 선택한 영웅의 범위를 금색 점선으로 보여 줍니다. 표시 영역은 맵 안으로 잘라 전당 UI와 겹치지 않습니다.

## 난이도

일반 몬스터와 보스의 체력을 직전 APK 대비 추가 50% 높였습니다. 전체 기준 배수는 1.20에서 1.80으로 변경했고, 모든 라운드·테마 등급에 적용합니다.

동일한 씨앗·자동 배치/구매 정책의 자동 플레이 12판 비교:

| 지표 | 직전 APK | 이번 변경 |
| --- | ---: | ---: |
| 도달 중간값 | 97탄 | 87탄 |
| 최소 도달 | 81탄 | 72탄 |
| 최고 도달 | 100탄 | 94탄 |
| 100탄 클리어 | 2판 | 0판 |

이는 자동 정책의 비교 결과이며 사람의 클리어율을 뜻하지 않습니다. 정책은 사거리별 최적 배치나 전투 중 이동을 수행하지 않습니다.
