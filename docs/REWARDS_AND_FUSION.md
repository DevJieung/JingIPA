# 성장과 이전 저장 호환

현재 신규 게임의 규칙은 [README.md](../README.md)를 따른다. 연속 수호전에서는
영웅을 하나씩 보유하고 중복 소환을 강화 포인트로 누적한다. 출전 6명과 대기 영웅은
편성 창에서 교체하며 상점에서 능력치와 패시브를 구매한다.

이전 웨이브 저장을 이어 하는 경우에만 5장의 대기 영웅을 합성하는 기존 흐름을 유지한다.
전장에 배치된 영웅은 재료로 쓸 수 없다. 합성 결과와 사용 재료는 저장되며 결과 확인을
여러 번 눌러도 영웅이 다시 지급되지 않는다.

광고 시청, 별 끌어오기, 광고를 통한 합성 복원·수정 회복·부활은 제거했다.
예전 버전에서 이미 지급된 보상은 저장 복구 시 보존한다. 삭제된 보상 창 대신 다음
유효한 화면으로 이동하며 골드나 영웅을 새로 지급하지 않는다.

검증: `tests/no_ads_check.tscn`, `tests/rules_check.tscn`,
`tests/progression_check.tscn`, `tests/arena_check.tscn`.
APK는 `tools/ci/check_no_ads.py`로 광고 리소스·SDK 클래스·권한이 없음을 검사한다.
