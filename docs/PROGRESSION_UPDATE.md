> 비교, 7,462개 문장 값, 위력 x1.30)과 「한국 출시 대응」 절의 문장/포커 표현 전환은

> [별맞춤 의식과 별 등급](STAR_RITE.md). 합성(+0.5성 보장 · 각성 수호자), 전투와 중간

> 소환은 「카드 5장」 대신 「의식 한 번(다시 돌리기 없음)」이다.

## 카드와 영웅

10개 족보 등급 안에서도 실제 포커 순서대로 숫자와 모든 키커를 비교한다.
원페어는 페어 숫자 → 나머지 세 숫자, 투페어는 높은 페어 → 낮은 페어 → 키커,
풀하우스는 트리플 → 페어, 포카드는 네 장 숫자 → 키커 순서다.
스트레이트의 A-2-3-4-5는 5가 가장 높은 조합이며 무늬에는 우열이 없다.

동률을 제외한 7,462개 포커 가치를 숫자 문장으로 영웅에 기록한다. 기존 캐릭터 원화·애니메이션을 유지하고
문장 배지와 상세 능력으로 변형을 표현한다. 서로 다른 수백만 손패마다 신규 원화를
만드는 방식은 아니다. 문장 위력은 같은 등급 기본 공격력에 최대 x1.30을 곱한다.
실제 공격, 도감/상세 정보, 편성 판단에 같은 수치를 사용한다.
저장에는 정수 순위를 담고 배수는 다시 계산하여 작은 키커 차이도 보존한다.
이전 저장의 문장이 없는 영웅은 x1.00으로 이어진다.

## 합성

대기 영웅 5장을 사용한다. 결과는 가장 높은 재료보다 최소 한 등급(0.5성) 높다.
선택 재료를 반영한 확률표에도 보장 아래 등급은 0%로 표시한다.
5성이 포함되면 별 상한은 유지하면서 각성 위력이 증가한다.

일반 소환은 기존 영웅만 준다. 합성은 파도의 수호자·화염의 군주·서리의 심판자·
천둥의 사도·균열의 파수꾼 중 하나를 준다. 각성 위력은 최소 x1.35이며,
재료에 각성 영웅이 있으면 가장 큰 각성 배수보다 x0.15 더 높다.
최고 문장 위력도 이어받는다. 각성 캐릭터는 기존 등급·속성 영웅의 원화와
전투 애니메이션을 공유하며 별도 이름·문장·도감 탭으로 구별한다.
결과 확인 전 광고로 재료를 되돌리는 기존 기능은 유지한다.

## 전투와 중간 성장

일반 탄은 60초, 보스 탄은 72초에 걸쳐 몬스터를 보낸다(1배속 시뮬레이션 기준).
전부 생성한 뒤 남은 적을 처리하는 시간이 추가되므로 전체 탄 길이는 편성·상태이상에
따라 달라진다. 몬스터 수는 초기 10~14마리에서 후반 일반 최대 82마리,
보스 호위 최대 38마리+보스 1마리로 늘린다. 동시에 살아 있는 적은 최대 41마리다.

중간 30초/36초에서 전투를 멈추고 무료 5장 소환 또는 선택한 출전 영웅의
0.5성 승급 중 하나를 제공한다. 최고 등급 영웅의 승급은 위력 x0.15 추가다.
전장이 가득 차거나 같은 캐릭터가 출전 중이면 소환 결과는 전당으로 간다.
성장 결과 확인 후 같은 전투를 이어가며 기존 투사체와 누적 피해는 유지한다.
같은 탄에서는 한 번만 받을 수 있다. 재접속으로 탄을 다시 시작할 때에도 이미 받은
성장은 유지하고 추가 지급하지 않는다. 저장에는 전투 중 벌이·처치·손실을 중복 반영하지 않는다.

수정 주변 우회 길을 추가하여 기본 이동 시간을 약 30.5초에서 36.8초로 늘렸다.
50개 맵의 실제 이름에 맞춘 지형·랜드마크를 추가했다.
치명타 균열빛·화면 흔들림과 짧은 저음/파열 효과음으로 타격을 강조한다.
추가 음원은 `tools/audio/build_impact_layers.py`로 만든 원본 합성음이며 외부 샘플을 쓰지 않는다.

## 간단한 이야기

균열 군단이 마을의 생명 수정을 노린다. 문장으로 수호자를 불러 수정을 지켜라.

## 한국 출시 대응

기본 표현은 숲·태양·파도·달 그림 문장과 2~14 숫자, 마법 조합 명칭이다.
메뉴에서 기존 포커 표현으로 바꿀 수 있으며 언어 선택과 독립적으로 저장한다.
현재는 표현 전환이며 포커 조합 판정·무작위 소환 규칙은 공유한다.
그림만 바꿨다는 이유로 이용등급이 낮아진다고 판단하지 않는다.

한국 배포 전 실제 제출 빌드의 규칙·보상·광고·스토어 설명과 포커 전환 기능까지
포함하여 등급분류 가능성을 확인해야 한다. 더 낮은 등급이 제품 요건으로 확정되면
포커 표현 전환을 제외한 별도 배포 설정과 독립적인 문장 조합 규칙을 검토한다.
이는 후속 제품 선택이며 이번 변경으로 한국 출시나 이용등급 승인을 완료한 것은 아니다.
배포 전 내용에 대한 등급분류 절차와 사행성 확인은
[게임산업진흥에 관한 법률 제21조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1025570393),
등급 고려 요소는 [문화체육관광부 이용등급 안내](https://www.mcst.go.kr/usr/child/info/policyPackage/grade.jsp)를 참고했다.

맵 참고는 [Kingdom Rush 공식 앱 소개](https://play.google.com/store/apps/details?id=com.ironhidegames.android.kingdomrush&hl=ko)의
경로를 따라 적을 막는 전략과 테마 식별성이다. 해당 게임의 이미지·맵·음원은 사용하지 않았다.

## 검증

`tests/progression_check.tscn`이 카드 비교/키커/무늬 동률, 실제 DPS,
저장 정밀도, 혼합 재료 승급 보장, 전용 영웅 소환 제외, 합성 원복,
중간 지원 정지/지급/재접속 중복 방지를 검사한다.
`tools/verify.sh`와 GitHub APK/IPA 공통 export 검사에 추가했다.

이번 실행에서 상세 성장 452건, 합성·보상 2,792건, 저장·흐름 563건,
스폰·동시 개체 상한 2,434건, 50개 맵 이동 450건, 화면 동작 329건,
한영 표시 1,117건과 화면을 눌러 진행하는 전체 흐름 검사가 통과했다.
광고 배치·취소·중복 보상·합성 복구 콜백 322건도 통과했다.
포커 판정은 2,598,960개 손패 전수, 문장 변형은 7,462개 고유 가치 전부를 검사했다.
자동 플레이 8판의 도달 탄 중간값은 83탄, 초반 6탄 수정 손실은 0이었다.
Android/iOS 실제 기기 플레이와 한국 이용등급 확정은 이번 로컬 검증 범위에 포함하지 않았다.
