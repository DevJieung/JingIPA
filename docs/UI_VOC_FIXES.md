# 영웅 정보 및 UI 수정 · 2026-09-09

`voc.jpg`에 표시된 영웅 상세창과 공통 UI를 수정했다.

- 영웅 미리보기는 idle 첫 프레임의 실제 불투명 영역을 읽고 가로·세로를 모두 프레임 안에 맞춘다. 활, 채찍, 넓은 장비가 다른 정보 위로 넘어가지 않는다. 영웅 목록과 전투 피해 목록의 미리보기에도 적용했다.
- 상세창의 그림·전투 정보·소개문·버튼을 분리했다. 현재 50명의 소개문은 모두 생략 없이 표시하며, 공통 줄바꿈은 실제 폰트 높이를 사용해 마지막 줄까지 영역 안에 둔다. 긴 어절과 명시적 줄바꿈도 처리한다.
- 우측 상단에 족보, 1~10등급 번호, 반 별 단위 희귀도를 함께 표시한다. 플러시는 `6등급 · 플러시`와 별 3개로 나온다.
- 큰 제목, 영문 이름, 한글, 숫자, 버튼을 모두 기존 번들 Refuge Sans로 통일했다. 글자 크기에 따른 픽셀 폰트 전환을 제거했다.
- 공격 설명을 `속성 / 타겟 / 패시브`로 나눴다. 실제 투사체의 단일·관통·연쇄·도탄·광역·장판 동작과 속성 효과의 확률·시간·배율을 표시한다. 특효 역할의 강화와 장착한 관통/연쇄 강화도 반영한다. 예: Niamh는 전기, 최대 3명 연쇄, 명중 시 16% 확률로 0.9초 마비.
- 버튼 장식을 간소화하고 금색 주요 동작, 밝은 테두리의 보조 동작, 비활성 및 눌림 상태를 구별했다. 눌린 그림도 원래 터치 영역 안에 머문다.

## 검증

- `tools/verify.sh quick --skip-sprites`: 전체 통과. 임포트, 부팅, 데이터 일치, 저장/거래/메뉴, 편성/이동, 실제 피해, 포커, 화면 순환, 자동 플레이, 글리프 검사.
- 50명 미리보기의 세 가지 프레임 크기(상세창/목록/전투 목록), 공격 설명 폭, 소개문 전체 표시를 검사해 오류 0건. 소개문은 모두 17px로 표시된다.
- 실제 Godot 렌더링: 1280×800 대표 화면 8장, 1000×625 영웅 상세창 50명 및 상점/전투/결과 화면 3장.
- 그림 원본과 전투 계산은 수정하지 않았다. 스프라이트 원본 검수 및 실제 Android 기기 설치/터치 검사는 수행하지 않았다.
