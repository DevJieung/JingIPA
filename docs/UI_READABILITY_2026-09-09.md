# 2026-09-09 · 가독성과 6인 편성 보완

`Sample.jpg` 피드백을 반영했다. 출전 인원은 6명이며, 좌측·중앙·우측에 네 곳씩 있는 12개 발판 사이에서 이동한다.

- 본문과 버튼은 번들 `Refuge Sans`로 표시한다. Noto Sans CJK KR Bold의 한글·라틴·UI 기호 서브셋이며, MSDF 렌더링으로 화면 축소에 대응한다. OS 글꼴 대체는 껐고 전체 표시 문자의 글리프를 확인했다. 큰 제목의 픽셀 글꼴은 유지했다.
- 버튼은 단색 중앙 바탕과 밝은 글자, 주요 동작은 금색 바탕과 어두운 글자를 사용한다. 목재 무늬의 농도를 줄이고 본문 대비를 높였다.
- 몬스터 예고, 체력 막대, 테마 소개에는 해당 몬스터의 속성 아이콘만 표시한다. 약점/면역 표식과 도움말의 상성 배수표, 전투 중 반복되는 `약점!` 문구를 제거했다. 실제 피해 계산과 전투 피해 통계는 유지한다.
- 영웅 머리 위와 목록 카드의 족보명을 별 표식으로 바꿨다. 열 등급은 반 별부터 다섯 별까지 반 별 단위로 채워진다. 도움말의 족보 목록에서 각 족보와 표식을 함께 볼 수 있다.
- 빈 발판에는 `+`와 `좌3`, `중4` 같은 위치 이름을 표시한다. 영웅 선택 시 선택한 발판은 금색, 이동/교환할 발판은 청록색 모서리로 강조한다. 배치 지도의 글자와 희귀도 표식은 지도 축소 변환 밖에서 그린다.
- 6명이 출전했으면 새 영웅은 전당으로 간다. 빈 발판이 있어도 일곱 번째 영웅을 출전시키지 않으며, 전당에서 고른 영웅과 교체할 전장 영웅을 선택하도록 안내한다.
- 이전 12인 저장은 앞의 6명을 출전 상태로 유지하고 나머지를 전당으로 옮긴다. 영웅 ID·중첩·기존 전당을 보존하며, 획득 팝업도 바뀐 전당 위치를 가리킨다. 새 저장은 `formation_v: 2`로 구별해 6명 초과 편성을 거절한다.
- Android 내보내기에서 삭제된 `icon.svg` 참조를 발견해 기존 크리스탈 이미지로 연결했다.

## 확인

- `tools/verify.sh quick --skip-sprites`: 통과. 임포트, 부팅, 데이터 정합성, 저장/거래/입력, 배치, 실제 피해 계산, 포커, 화면 순환, 자동 플레이, 글리프 확인.
- 최종 배치 회귀 검사: **87건, 실패 0건**. 모든 12개 발판 사용, 6명 초과 출전 차단, 교체, 저장 이전과 획득 결과 위치 갱신 포함.
- 최종 게임 흐름 회귀 검사: **107건, 실패 0건**.
- 실제 Godot 화면을 1280×800과 기본 창 크기 1000×625에서 확인했다.
- 자동 플레이 4판은 87~98탄 도달, 중간값 95탄, 클리어 0판이었다. 1~6탄 크리스탈 손실은 없었다. 이번 변경은 출전 수와 UI를 수정한 것으로, 6인 편성의 후반 난이도에 대한 추가 조정은 별도 검토가 필요하다.
- 캐릭터 그림과 애니메이션은 수정하지 않아 전체 스프라이트 검수는 생략했다. 실제 Android 기기의 설치/터치 검증은 수행하지 않았다.
