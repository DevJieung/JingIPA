# 개구리 용사 (Frog Warrior) — 수학 모험

초등 1~2학년(만 7~8세)을 위한 사칙연산 퀴즈 게임. **Godot 4.7.1**, 안드로이드/iOS 동시 배포.

개구리 용사가 나쁜 뱀을 한 마리씩 물리치며 18개의 "탄"을 깨 나갑니다.
문제를 풀면 **블록으로 실제 연산 과정을 먼저 보여주고**, 그 다음에 정답/오답이 갈립니다.

기준 화면은 **가로 태블릿 1280×800** 입니다. 폰 세로로 열어도 배치가 알아서 바뀝니다.


아이가 "설명을 보고 → 답을 고른다"는 순서를 따로 배우지 않아도 됩니다.

설명이 보이는 모습은 달라지지 않습니다.

## 이 게임이 보통 수학 앱과 다른 점

**0. 그림은 이 PC의 Krea 2로 만들었습니다.**
개구리·뱀·로고·타이틀·월드 지도 6장·전투 배경 6장 — 전부 로컬 Krea 2 Turbo 생성물입니다
(`python3 tools/gen_art.py`, 약 20분). 캐릭터는 기본 포즈를 만든 뒤 i2i로 표정만 바꿔
같은 캐릭터가 유지되게 했습니다. 블록·버튼·UI는 여전히 코드로 그려서 어떤 해상도에서도 선명합니다.
**그림이 없어도 게임은 그대로 돌아갑니다** — 없으면 예전처럼 코드로 그린 그래픽으로 대체됩니다.

**1. 설명 순서가 곧 수업입니다.**
문제 카드의 **왼쪽 숫자가 커지며 강조** → 왼쪽 격자에 블록이 하나씩 딱딱딱
→ 오른쪽 숫자 강조 → 오른쪽 격자도 똑같이 → 그다음이 갈립니다:

- **덧셈**: 두 격자를 합산판에 순서대로 **쏟습니다**.
- **뺄셈**: 왼쪽 격자만 합산판에 쏟고, 오른쪽의 **붉은 블록이 하나씩 날아가 박치기**해서
  판의 블록과 함께 사라집니다. "덜어낸다"가 1:1로 눈에 남습니다.

여기까지의 흐름(격자 → 격자 → 판)이 덧셈·뺄셈에서 완전히 같아서 아이가 화면을 다시 배우지 않습니다.

**1-1. 식은 답을 고르기 전부터 아래에도 적혀 있습니다.**
격자와 **`+`·`−`, 그리고 합산판 왼쪽의 `=` 까지** 처음부터 깔려 있습니다 —
위 줄이 `[격자] + [격자]`, 아래 줄이 `= [합산판]` 이라 식을 두 줄로 옮겨 적은 그림이 됩니다.
기호가 시연 도중에 등장하면, 정작 아이가 답을 고르는 순간의 화면에는
무슨 계산인지가 빠져 있게 됩니다.

**2. 블록이 진짜로 십진법을 보여줍니다.**
격자는 문제 크기와 상관없이 **항상 같은 칸 수**입니다 — 항 격자 10칸, 합산판 20칸.
칸 수가 매번 바뀌면 아이가 화면을 다시 읽어야 합니다.
합산판은 5칸씩 두 줄인 **십틀 두 개**라, 앞 틀이 꽉 차고 뒤 틀로 넘어가는 것이 곧 받아올림입니다.
(예전에는 10이 차는 순간 금색으로 묶는 연출이 따로 있었지만, 한 문제마다 2초 가까이
잡아먹어 아이가 기다리는 시간이 계산하는 시간보다 길어져서 걷어냈습니다.)
합쳐진 뒤에도 블록은 원래 색을 유지해서 7 + 5 로 만든 10 안에 7과 3이 그대로 보입니다.

**2-1. 초록은 뜻이 하나입니다 — "내가 찾아야 할 것".**
`?` 가 나타나는 격자만 초록입니다. `3 + 2 = ?` 면 합산판이, `4 + □ = 10` 이면 □ 자리 격자가 초록이고,
이미 아는 수가 놓이는 격자는 절대 초록이 아닙니다. 보기 버튼·물음표 상자와 같은 색이라
아이가 "저 초록을 채우면 된다"를 화면마다 다시 배우지 않습니다.

**2-2. `4 + □ = 10` 은 격자를 셋 다 깝니다.**
왼쪽 격자(4), **□ 자리 격자(초록, 아래에 "?")**, 그리고 합산판(10). 식과 화면이 같은 그림입니다.
답을 고르면 초록 격자에 블록이 하나씩 놓이는데 **정확히 같은 순간에 합산판도 한 칸씩 늘어납니다.**
"□ 에 하나 넣으면 저쪽도 하나 늘어난다" 는 그 대응이 이 문제 유형이 가르치는 전부입니다.

**3. 오답이 아무 숫자가 아닙니다.**
`7 + 5` 의 오답 보기에는 **2**가 들어갑니다(받아올림을 잊은 답).
`12 − 3` 에는 **1**이 들어갑니다(자리마다 큰 수에서 작은 수를 뺀 답 — Brown & Burton 1978의 대표 버그).
아이가 어떤 오답을 골랐는지 유형별로 기록되어 부모 화면에 나옵니다.

**4. 벌주지 않습니다. 목숨도 없습니다.**
- 타이머·카운트다운·재촉 연출이 **하나도 없습니다** (시간 압박은 이 나이대 수학 불안의 주 원인).
- **목숨(하트)이 없습니다.** 시도 횟수 제한도, 게임 오버도 없습니다.
  마음 놓고 여러 번 눌러볼 수 있어야 "위치 찍기"가 아니라 "계산 다시 하기"를 합니다.
- 1차 오답: 과정만 시연하고 답은 가립니다 — 블록을 세면 답이 나옵니다.
- 2차 오답: 다시 천천히 시연 (숙달 단축 해제).
- 3차 오답: 답까지 보여준 뒤 정답 보기를 반짝여 눌러보게 하고, **보상은 정답과 똑같이** 줍니다.
  이후 3문항은 한 단계 쉬운 문제로 낮춰 발판을 놓습니다.
- 맞혀도 **바로 넘어가지 않습니다.** 개구리가 뱀을 먹는 걸 보고, 스스로 **다음** 을 눌러야 넘어갑니다.
  (타이틀의 **설명 건너뛰기** 를 켜면 시연 없이 곧바로 다음 문제로 갑니다 — 이미 아는 아이용.)
- 한 세션 20문제에서 "오늘은 여기까지"로 마칩니다 (부모 화면에서 해제 가능).

**5. 교육과정 순서를 그대로 따릅니다.**
2022 개정 교육과정 초1~2 '수와 연산' 지도 순서 그대로 18탄.
곱셈구구도 교과서 순서(2·5 → 3·6 → 4·8 → 7·9 → 1단)이고,
곱셈 표기는 한국 교과서식 **(한 묶음의 크기) × (묶음의 수)** = "3씩 4묶음 = 3 × 4" 입니다.

**6. 외부 이미지 에셋이 0개입니다.**
개구리, 뱀, 배경, 블록, 버튼 — 전부 코드로 그립니다. 효과음과 배경음도 파이썬으로 합성합니다.
그래서 어떤 해상도에서도 선명하고, 앱 용량이 매우 작습니다.

**7. 한국어 / English.** 타이틀 화면에서 한 번 눌러 바꿉니다. 화면의 모든 글자가 바뀌고
설정은 저장됩니다. 문제는 원래 숫자와 기호뿐이라 언어와 무관합니다.

**8. 통신을 하지 않습니다.** 광고 없음, 결제 없음, 분석 도구 없음, 네트워크 권한 없음, 계정 없음.

## 진행 구조 (6 월드 × 3 탄 = 18 탄)

| 월드 | 탄 | 내용 | 교과 |
|---|---|---|---|
| 개굴 늪지 | 1~3 | 합 5 이하 → 합 6~9 → 한 자리 뺄셈 | 1-1 3단원 |
| 연꽃 호수 | 4~6 | 10 모으기·가르기 → 십몇 + 몇 → 십몇 − 몇 (받아올림/내림 없음) | 1-1 5단원, 1-2 2단원 |
| 버섯 숲 | 7~9 | 세 수의 계산 → 10을 만들어 더하기 → **받아올림** (몇)+(몇) | 1-2 4·6단원 |
| 안개 동굴 | 10~12 | **받아내림** (십몇)−(몇) → 20까지 더하기 → 20까지 빼기 | 1-2 6단원 |
| 곱셈 신전 | 13~15 | 곱셈의 뜻(몇씩 몇 묶음) → 2·5단 → 3·6단 | 2-1 6단원, 2-2 2단원 |
| 뱀왕의 성 | 16~18 | 4·8단 → 7·9단 → 1단·0의 곱 총력전 | 2-2 2단원 |

각 월드의 마지막 탄은 보스전(문제 8~10개, 큰 뱀). 18탄을 깨면 **무한 도전**이 열립니다.

> **덧셈과 뺄셈은 전부 20 이내입니다** (최대 10 + 10 = 20). 그래서 합산판 20칸 하나로
> 모든 덧셈·뺄셈 문제가 표현됩니다. 곱셈만 배열 모델로 81까지 갑니다.

## 바로 실행하기

Godot 4.7.1 편집기가 이미 이 PC에 설치되어 있습니다 (`~/.local/bin/godot`, PATH 등록됨).

> ⚠️ **이 개발 머신(spark-006f)은 화면이 없는 SSH 전용 서버입니다** (`XDG_SESSION_TYPE=tty`).
> `godot --path .` 로 창을 띄우려 하면 `Unable to create DisplayServer` 로 종료됩니다.
> 눈으로 보려면 아래 **브라우저로 플레이** 를 쓰세요.

```bash
cd ~/pjt/mathgame

# 자동 검증 (화면 불필요) — 문제 생성기 + 블록 시연 + 전투 루프 전체
godot --headless --path . res://tests/test_runner.tscn

# 화면이 있는 PC(Mac 등)에서라면 이렇게 바로 실행/편집됩니다
godot --path .        # 게임 실행 (450x800 창)
godot -e --path .     # 편집기 열기
```

### 브라우저로 플레이 (이 서버에서 눈으로 확인하는 방법)

웹으로 빌드해서 다른 기기의 브라우저로 접속합니다. 터치도 그대로 동작하므로
**아이 폰 브라우저로 열어 실제 조작감까지** 확인할 수 있습니다.

```bash
mkdir -p build/web
godot --headless --path . --export-release "Web" "$PWD/build/web/index.html"
```

> ★ **Godot 웹 빌드는 '보안 컨텍스트'를 요구합니다** (오디오 워크릿 때문).
> 평문 HTTP + IP 주소로 열면 `Secure Context - Check web server configuration (use HTTPS)`
> 오류가 납니다. 보안 컨텍스트로 인정되는 건 **`localhost`** 아니면 **HTTPS** 둘뿐입니다.

**방법 A — 내 PC 브라우저로만 볼 때 (경고 없음, 가장 간단)**

```bash
python3 tools/serve_web.py --host 127.0.0.1 --port 8060    # 서버 쪽
ssh -L 8060:localhost:8060 dgxmaruta@spark-006f            # 내 PC 쪽
#  브라우저에서 http://localhost:8060/
```

**방법 B — 폰 등 다른 기기에서도 볼 때 (자체 서명 HTTPS)**

```bash
python3 tools/serve_web.py --https --port 8443
#  브라우저에서 https://spark-006f.tailec6e70.ts.net:8443/
```

`.certs/dev.crt` 를 자동 생성합니다 (tailscale IP·MagicDNS 이름 포함).
첫 접속 시 "안전하지 않음" 경고가 뜨는데 **[고급] → [계속 진행]** 한 번 누르면 됩니다.
그 뒤로는 보안 컨텍스트로 인정되어 게임이 정상 실행됩니다.

경고까지 없애려면 tailnet 관리 콘솔에서 HTTPS 를 켜고 진짜 인증서를 받으면 됩니다:

```bash
sudo tailscale cert --cert-file .certs/dev.crt --key-file .certs/dev.key \
     spark-006f.tailec6e70.ts.net
```

첫 로딩만 약 42MB 받고 이후에는 캐시됩니다.

에셋을 다시 만들 때:

```bash
python3 tools/gen_audio.py    # 효과음 19개 + 배경음 2개 (약 790 KB)
python3 tools/gen_icons.py    # 앱 아이콘 / 런치 스크린 / 안드로이드 런처 아이콘
python3 tools/check_font.py   # 화면에 쓰는 글자가 전부 폰트에 있는지 검사
python3 tools/gen_art.py      # Krea 2 로 그림 20장 재생성 (약 20분, GPU 필요)
python3 tools/gen_art.py --list   # 무엇을 만드는지 목록만
```
