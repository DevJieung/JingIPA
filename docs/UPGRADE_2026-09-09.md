# 2026-09-09 · 픽셀 UI와 NewMap 전장

> 아래는 초기 NewMap 구현 기록이다. 현재 규칙은 **출전 6명 / 배치 12곳**이며,
> 후속 글꼴·버튼·속성·희귀도 변경은 [가독성 보완 기록](UI_READABILITY_2026-09-09.md)을 따른다.

메인, 포커, 야영지(상점/정비), 편성, 전투 기록, 게임 종료 화면을 같은 픽셀 UI로 연결했다.
`NewMap.jpg`를 기준으로 두 입구와 12개 발판을 구현했으며 전투 중에도 배치를 바꿀 수 있다.

## 화면과 조작

- 메인 이어하기/새로 시작, 카드 교체, 상점 구매 버튼: Krea 목재·황동 소재, 픽셀 테두리, 눌림/비활성 상태.
- 야영지와 포커 화면: 같은 청록 천막·황동 등불·석조 성소 배경. 설명 뒤에는 목재 패널을 깔아 대비 확보.
- 크리스탈 정비: 석재 제단 위에 실제 크리스탈 그림을 모아서 표시.
- 한국어 픽셀 폰트를 공통 그리기 함수에서 직접 불러온다. Godot 기본 폰트를 읽던 경로를 수정했다.
- 상점 **캐릭터 배치** 탭에서 다음 탄의 몬스터를 보고 배치한다.
- 매 탄 족보 확정 후 **전장 배치 팝업**을 연다. `배치 완료 · 전투 시작`을 눌러 진행한다.
- 영웅 선택 후 발판 클릭 또는 영웅을 발판으로 드래그. 찬 발판이면 서로 위치 교환.
- 전당 영웅 선택 후 발판 클릭으로 참전. 찬 발판의 기존 영웅은 전당으로 간다.
- **영웅 정보** 탭의 상세 능력치, 전당 스크롤, 등급순 정렬 유지. 출전 12명은 6열 2행.
- 전투 중에는 전장 영웅/오른쪽 정보 행을 선택한 뒤 발판 클릭, 또는 드래그한다.
  전투는 계속 진행하며 이동에 골드를 쓰지 않는다. 취소 버튼 또는 같은 발판 클릭으로 선택 해제.
- 전투 정보판에 12명 모두 표시. 결과 팝업은 7명 이상이면 두 열로 나눠 12명의 전과를 표시한다.
- 메뉴 버튼은 상단으로 옮겨 상점 구매 버튼과 전투 이동 안내를 가리지 않게 했다.

## 전장과 저장

`Balance.ROUTE_POINTS`가 좌상단 경로를 정의하고, 중앙을 기준으로 대칭한 경로가 우하단 입구다.
두 직각 경로가 교차하지 않고 중앙 제단 양쪽에 도착한다. 등장 순서는 두 입구를 번갈아 사용한다.
그리기와 시뮬레이터가 같은 좌표 함수를 쓰며 몬스터의 전방 방향, 유도탄, 위치 캐시에도 경로 번호를 적용했다.
모서리에서는 좌우 분산을 좁혀 순간이동 없이 이어진다. 경로 2,064px, 기본 속도 82px/s로 약 25.2초.

`Balance.POST_POINTS`: 좌측 L1~L4, 중앙 C1~C4, 우측 R1~R4. 동시에 12명 참전한다.
사거리 제한 없이 선두부터 공격하는 기존 규칙은 유지한다. 위치가 총구/발사 원점을 바꾼다.
이동 후에도 영웅의 전투 ID, 공격 대기시간, 시전 중 공격, 발사한 탄, 피해/처치 누적을 보존한다.

영웅의 `post` 필드에 배치 지점을 저장한다. 배열 순서와 실제 위치를 분리하여 전투 도중 재정렬하지 않는다.
기존 v7 저장 중 `post`가 없는 영웅에는 빈 발판을 자동 배정한다. 기존 영웅/전당/중첩을 보존하고,
범위 밖·중복·잘못된 타입의 배치가 든 저장은 현재 판을 바꾸기 전에 거절한다.

전투 이어하기는 해당 탄 시작부터 재시작한다. 이동 저장은 탄 시작 체크포인트의 **배치만** 갱신하므로
중간에 번 골드·처치·크리스탈 손실이 재시작 때 중복되지 않는다.

## 생성 소재와 글꼴

사용한 모델은 이 PC에 설치된 **Krea 2 Turbo**다. OpenAI 이미지 도구/API는 사용하지 않았다.
기존 `tools/gen_art.py`의 화풍 앵커와 픽셀 후처리, `gpu_guard`를 재사용했다.

| 소재 | 파일 | 용도 |
|---|---|---|
| 야영지 | [camp.png](../art/ui/refuge/camp.png) | 포커·상점·편성·종료 배경 |
| 목재 | [wood.png](../art/ui/refuge/wood.png) | 정보판과 공통 UI 표면 |
| 석재 | [stone.png](../art/ui/refuge/stone.png) | 전장과 크리스탈 제단 |
| 조각 버튼 | [button.png](../art/ui/refuge/button.png) | 끝 장식을 유지하고 가운데를 늘리는 버튼 |

전체 프롬프트와 시드: [prompts.json](../art/ui/refuge/prompts.json).
재생성: `python3 tools/gen_ui_refresh.py`. 이미 있는 소재는 유지한다.

글꼴: [NeoDunggeunmo Pro 원본 프로젝트](https://github.com/neodgm/neodgm-pro),
[번들 라이선스](../core/fonts/NeoDunggeunmoPro-LICENSE.txt).
`core/fonts/NeoDunggeunmoPro.ttf` 사용. OS 글꼴 대체와 안티앨리어싱을 끄고 모든 표시 문자의 글리프를 검사했다.

  클릭/드래그, 맵 밖 드롭, 기존 저장 마이그레이션, 손상 저장 거절, 이동 중 공격 상태 유지,
  전투 저장의 보상 중복 방지, 정비 탭, 포커 후 팝업, 영웅 정보 12자리, 메뉴 일시정지 포함.

  이는 새 기능의 회귀 검증 표본이다. 12인 편성의 난이도가 기존 6인 편성과 같다는 보장은 아니며
  적 체력/골드 곡선을 이번 UI·배치 변경에서 별도로 재조정하지 않았다.
- 실제 Godot 렌더링: 타이틀, 카드, 강화, 패시브, 크리스탈 정비, 정비 배치, 포커 후 배치,
  영웅 정보, 전장, 이동 선택, 12인 전투 기록, 종료 화면 확인.
- Android debug APK: 빌드 및 `apksigner verify` 통과. 실제 Android 기기 설치/터치 검증은 수행하지 않았다.
- 캐릭터 애니메이션 시트 자체는 수정하지 않았으며 기존 스프라이트 검수는 이번 실행에서 제외했다.
